# Crypto Wallet App

A modern, sleek blockchain wallet application built with Flutter.

## Overview
This application provides a secure and intuitive interface for managing digital assets. It features a dark-themed, premium design and includes the following key features:
- **Dashboard:** View total balance, quick actions (Send, Receive, Buy), and recent market activity.
- **Assets/Portfolio:** Manage multiple cryptocurrency holdings with real-time price tracking.
- **Transaction History:** Detailed log of all past transactions.

## Tech Stack
- Flutter ^3.7.2
- Google Fonts
- Lucide Icons

## Setup
1. Run `flutter pub get` to install dependencies.
2. Run `flutter run` to start the app.
